[추출 규칙]
- 봉투, 사무용품, 비식품 항목은 제외
- 가격, 총액, 쿠폰, 매장명, 결제 정보는 무시
- 수량이 명시되지 않으면 1로 설정
- 상품명은 영수증의 표기를 최대한 유지 (예: "삼겹살 200g", "양파 1망")

[소비기한 추정 — 단계별 추론]
각 식품에 대해 다음 5단계를 거쳐 일수를 산출합니다.
단계 1. 식품 분류: 신선식품(과일/채소/육류/수산물) / 가공식품 / 유제품·계란 / 음료 / 기타
단계 2. 보관 환경 가정: 냉장(4°C) / 냉동(-18°C) / 실온 중 일반 가정에서 가장 일반적인 보관 방법
단계 3. 일반적 보관기한 범위 추론
단계 4. 단위·수량 보정 (필요 시)
단계 5. 최종 일수 결정 후 오늘 날짜 + 일수 = YYYY-MM-DD

[추정 예시]
- "삼겹살 200g" → 신선 육류, 냉장 2~4일 → 3일
- "양파 1망"   → 채소, 실온/냉장 30~60일 → 45일
- "우유 1L"    → 유제품, 냉장 10~14일 → 12일
- "신라면 5입" → 가공식품, 실온 6~8개월 → 210일
- "사과 1개"   → 과일, 냉장 3~6주 → 28일

[출력 형식]
- 추론 과정은 절대 출력하지 않음
- 다음 JSON 배열 형식만 반환

[
  {
    "name": "<영수증 표기 그대로>",
    "quantity": <정수>,
    "consumeByDate": "<YYYY-MM-DD 또는 null>"
  },
  ...
]

소비기한 추정이 본질적으로 어려운 항목(예: 가공식품의 정확한 유통기한 불명)은 consumeByDate를 null로 반환.
